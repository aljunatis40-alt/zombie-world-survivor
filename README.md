# ZOMBIE WORLD: SURVIVOR

An expandable 3D open-world zombie survival game for Android, built with Godot 4.

## Project direction
- Third-person survivor gameplay
- Touch-first mobile controls
- Zombie AI, combat, health, and survival systems
- Scalable 3D world and graphics settings
- Original stylized characters and environments

## Development status
Project foundation is being assembled. An Android build will be considered ready only after a successful Godot export and device testing.
