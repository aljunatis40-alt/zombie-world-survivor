# Mobile UI layout standards

- Lock the game to landscape orientation on Android at launch.
- Keep the gameplay viewport responsive with an expanding aspect mode.
- Keep status information in the upper-left safe area.
- Keep the virtual movement joystick in the lower-left quadrant.
- Reserve the right half for camera look gestures; do not place labels across this zone.
- Group FIRE, RELOAD, JUMP, and RUN buttons at the lower-right with consistent spacing.
- Use readable high-contrast text, subtle outlines/shadows, and translucent controls.
- Keep controls away from screen edges to reduce accidental Android system-gesture conflicts.
- Re-check positions on 16:9, 20:9, and tablet aspect ratios before release.
