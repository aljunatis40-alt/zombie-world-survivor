# Development roadmap

## Foundation
- [x] Godot 4 project structure
- [x] Third-person survivor controller and follow camera
- [x] Touch movement/look input and fire button
- [x] Basic zombie chase, melee damage, and health
- [x] Procedural graybox abandoned district

## Next production milestones
- [ ] Import original high-quality survivor and zombie character assets

- [ ] Add weapon models, reload, muzzle flash, hit effects, and audio
- [ ] Expand world with interiors, roads, props, loot, and mission locations
- [ ] Add save system, inventory, crafting, and mission progression
- [ ] Add graphics presets and device-specific performance profiling
- [ ] Configure Android export and verify on a physical device

The current geometry is a functional blockout, not final art. No APK is declared ready until exported and tested.
